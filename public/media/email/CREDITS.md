# Email artwork provenance

The PNGs here are unmodified copies from the Tavi branding checkout's `brand/` assets (branch `brand/assets`, commit `629ba96`). They are rendered from the real Tavi character and brand artwork by `video/src/brand/Brand.tsx`:

- `tavi-wordmark.png`: `brand/logo/tavi-wordmark.png`.
- `tavi-wave.png`, `tavi-happy.png`, `tavi-cheer.png`, `tavi-hmm.png`, `tavi-smug.png`, `tavi-hype.png`, `tavi-lol.png`, `tavi-ooh.png`: matching files in `brand/expressions/`.

The character is adapted from **Mascot / Avatar Customization** by **alisketch**, licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). [Original artwork](https://rive.app/marketplace/27479-51911-mascot-avatar-customization/). Changes include runtime posing, expressions, recoloring, and staging for Tavi. Not endorsed by alisketch. Keep the attribution in the email footer when using this artwork.

The email renderer displays these PNGs at smaller dimensions; the original files are preserved. They must be served at the public site's `/media/email/` path before live sending is enabled. The local preview server provides these exact files for design review.
