# Roadmap

Build and verify one usable milestone at a time:

1. Refine the reusable character rig and expressive performances.
2. Improve attention, internal state and reaction timing.
3. Add microphone input and transcription.
4. Introduce bounded contextual AI through the existing reaction policy.
5. Verify customization, recovery and the installed OBS workflow.

These are planned directions, not a list of shipped features.
