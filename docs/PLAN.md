# Tavi delivery plan

The current project-wide implementation roadmap is [IMPLEMENTATION-PLAN.md](./IMPLEMENTATION-PLAN.md). It supersedes the earlier foundation checklist and reflects the Rive integration.

Eight days total, solo developer: target a complete end-to-end build in four days, then four days for refinement and testing. These are relative checkpoints, not a reset of the project clock.

## Next checkpoints

1. Finish expressive performances and audit actual rig capabilities.
2. Add attention, restrained idle behavior, and shared reaction timing/priority.
3. Connect microphone input and transcription to real streamer reactions.
4. Add bounded contextual AI and selective Twitch participation.
5. Complete one convincing OBS scene and honest supported customization.
6. Verify the installed Tauri flow, rehearse the demo, and use refinement time for polish and reliability.
