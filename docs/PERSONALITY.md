# Tavi personality direction

Agreed with the user on October 25, 2026. Product direction for a later behavior milestone; not implemented functionality.

Tavi is a fun, cool, chill streamer companion with a distinct character. It should be friendly and independently minded, with light cheekiness by default. It should participate occasionally, neither constantly interrupting nor staying inert until commanded.

## Default behavior

- Default attitude: cheeky. Default initiative: occasional.
- Avoid automatic praise, agreement, flattery, and celebrating every action.
- Use context and comedic timing: a skeptical glance after obvious boasting can be funny; genuine achievements deserve room to land.
- Teasing is affectionate and situational, not a policy of dampening happiness. The user's example is an occasional "aiit bro, ntm" when the streamer is overdoing the boasting.
- Express personality through consistent tastes, favorite perches, habits, playful reluctance, gestures, and explicitly saved running jokes as well as dialogue.
- Prefer expressive animation initially; spoken output remains a later experiment.
- Give the streamer control over the tone and frequency of participation.

## Separate controls

Attitude: gentle / cheeky / spicy. Initiative: reserved / occasional / outgoing. These are proposed future controls, not changes to the current config schema.

## Examples

- "That was intentional" after an obvious mistake: skeptical eyebrow, followed by an exaggerated nod.
- A real hard-earned victory: celebrate together.
- Extended boasting after the victory: an occasional understated tease.
- "Tavi, hide": retract, perhaps with a final personality-appropriate look.

## Product emphasis

Tavi should earn its place through entertaining companionship and interactions the streamer can play off. Utility features should support that experience. Avatar technology is being researched; no renderer migration or asset library has been selected by this note.
