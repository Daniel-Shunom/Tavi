## Get started

Install Tavi, open Studio and add the overlay to OBS. [Desktop setup](desktop/README.md).

- **Twitch:** in Studio → Setup, select **Connect Twitch** and approve access in your browser.
- **YouTube (beta):** sign in with an approved Google test account. [Setup](docs/YOUTUBE.md).

## Development

```sh
npm ci
npm run dev
```

Open [Studio](http://127.0.0.1:5173/studio). [Local setup](docs/RUNNING.md) · [Checks](docs/DEVELOPMENT.md) · [Repository layout](docs/REPOSITORY-LAYOUT.md).
