# Tavi expressive 2D workspace

An isolated Rive authoring workspace. `fallback/` preserves the original runtime artwork and hashes.

```sh
python tools/tavi-rive-lab/build.py
rive art/tavi-rive-lab/project
```

Use an existing Rive CLI installation for the preview command. See [authoring reference](AUTHORING.md) for expressions, turns, walking, sitting and climbing.
