# Tavi brand assets

- `logo/`: wordmarks, lockup and app icon.
- `screenshots/`: landing, Studio and OBS captures.
- `expressions/`: full-body character cutouts.
- `emotes/`: head crops in supported export sizes.
- `store/`: store artwork.
- `social/`: link-preview image.

The app and installer icons use `logo/tavi-icon-1024.png`; regenerate them with `npm run icon` in `desktop/`.
